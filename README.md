# Полка

Настольная коллекция для Windows с .NET Framework 4.x. Откройте Polka.exe. Для сборки из Polka.cs запустите build.cmd.

Добавляйте произведения, выбирайте формат и один из трёх приоритетов. В списке сначала идут записи с высоким приоритетом. Для редактирования дважды щёлкните по карточке. Поиск работает по названию.

Через шестерёнку в правом верхнем углу можно выбрать бело-голубую или графитово-красную тему и переименовать каждый уровень приоритета. Нажмите «Сохранить», чтобы применить настройки. Новые подписи распространяются на существующие записи с тем же уровнем.

Коллекция хранится в %LOCALAPPDATA%\Polka\library.xml, оформление и подписи — в settings.xml рядом с ней. Для резервной копии закройте приложение и скопируйте оба файла.
